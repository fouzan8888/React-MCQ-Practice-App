# QuizForge – React MCQ Practice App

A responsive multiple-choice practice application built with React and Vite.

## Features
- Java, React and Python question categories
- Multiple-choice quiz flow with question navigation
- Answer selection and progress indicator
- Session timer
- Score and accuracy calculation
- Answer review with explanations
- Recent attempt history saved in browser localStorage
- Responsive layout for desktop and mobile

## Run locally
1. Install Node.js (18 or newer).
2. Extract this project and open a terminal in the project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Production build
Run `npm run build`. The production-ready files are generated in `dist/`.

## Notes
This is a frontend practice project. Questions are stored locally in `src/questions.js`; there is no backend, authentication, external API or server-side database.
